# 演習終了時：作業を保存してCodespaceを停止する

**講義の最後に、講師の案内で実行してください。** 演習の途中では停止しません。

1. 編集したファイルを保存し、作業ブランチへのcommit・pushを確認する。
2. Issue・PRのURLと、未完了の作業を記録する。
3. 必要なSARIFは、ファイル一覧の右クリックからダウンロードする。Git管理対象外のためpushでは保存されない。
4. アプリ用ターミナルでCtrl+Cを押す。
5. コマンドパレットから`Codespaces: Stop Current Codespace`を選ぶ。見つからなければGitHubのCodespaces一覧から対象を停止する。

ブラウザを閉じるだけでは停止になりません。停止後も保存容量は使用量に含まれます。不要なCodespaceを削除する場合は、必要なファイルがGitHubなどに保存されていることを先に確認してください。
